Excel Sales Analysis Dashboard
📌 Project Overview

This project focuses on analyzing sales data using Microsoft Excel to identify business trends, measure key performance indicators (KPIs), and generate actionable insights.

The project demonstrates practical Excel skills including data cleaning, data analysis, Pivot Tables, formulas, charts, and dashboard creation.

🛠️ Tools & Technologies
Microsoft Excel
Excel Formulas
Pivot Tables
Pivot Charts
Data Cleaning
Data Visualization
Dashboard Design
📊 Project Objectives

The main objectives of this project are to:

Analyze overall sales performance
Identify top-performing products and categories
Analyze sales and profit trends
Compare regional performance
Identify important business KPIs
Build an interactive and easy-to-understand dashboard
Extract meaningful insights from raw sales data
🔍 Analysis Performed
Data Cleaning
Removed duplicate records
Handled missing or inconsistent values
Standardized data where required
Prepared the dataset for analysis
Data Analysis
Calculated key sales metrics
Analyzed sales by product/category
Compared regional performance
Examined sales trends over time
Identified top and bottom performers
Dashboard

An interactive Excel dashboard was created to provide a visual overview of the most important business metrics and trends.
